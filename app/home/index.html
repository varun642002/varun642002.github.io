09 / Principles

  
How Iwork.

  

    
01
Measure first
Coming from BI, I look at the data before deciding on a fix — define the measurement before trusting the number.

    
02
Real data only
No fake health numbers, no fake charts. If a feature can't be honest yet, it says so.

    
03
Ship the whole path
Dashboard, backend, mobile client and the CI that deploys it — a project is done when the last step works.
